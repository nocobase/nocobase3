# Developing with AI

:::warning Being written
This page is still being written.
:::

An application carries three layers of guidance for AI:

- **`AGENTS.md`** — the rules that apply everywhere, read first
- **`skills/nocobase-app-development/`** — the application's own development guide, one page per task
- **`.agents/skills/`** — the skills each installed plugin publishes, synced when the plugin is registered

This page explains how the three fit together and how to keep them accurate as the application grows.
