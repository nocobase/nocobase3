认证、权限、工作流这类需求，装上插件就有。注册插件时，它的技能文档会同步到项目里，AI 在使用前会先读它。

## 本节将覆盖

- **使用插件** —— 安装、接线，以及插件技能如何同步
- **认证与权限** —— 登录注册、会话、角色与数据权限
- **工作流** —— 审批与多步流程
- **文件、通知、国际化** —— 其余内置插件
- **开发插件** —— 只在需要发布成可复用包时才需要；应用自己的功能直接写在应用里
