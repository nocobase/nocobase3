业务代码写在你自己的源码里。创建应用时生成的 `client/`、`server/`、`database/` 都归你所有，可以直接编辑——不需要为了加一个功能去写插件。

## 本节将覆盖

- **让 AI 参与开发** —— `AGENTS.md` 与 `skills/` 如何让 AI 按项目约定写代码
- **页面与路由** —— 声明路由、编写页面、注册导航入口
- **界面与样式** —— shadcn/ui 组件与语义化 Tailwind 令牌
- **API 接口** —— HTTP 端点、Webhook，以及每条路由自己的认证与鉴权
- **数据读写** —— 运行时查询与写入
- **数据库迁移** —— 表结构变更与种子数据
- **服务与后台任务** —— 领域逻辑复用、后台任务与定时任务
- **国际化** —— 让每一处用户可见的文案可翻译
- **测试与验证** —— 测试放在哪里、改动之后验证什么
