# 和 AI Agent 协作

跑通[第一个功能](../get-started/first-feature.md)后，你已经经历了一轮「说明需求、修改代码、运行检查、查看结果」。后面的功能也可以按这个节奏推进。

这一部分讲的是在应用项目中使用AI Agent。应用里的 AI 员工和知识库属于[内置能力](../capabilities/index.md)，不需要先配置它们才能让AI Agent写代码。

## 这一部分适合什么时候读

当你已经能运行应用，准备持续增加功能时，这一部分帮助你建立可重复的协作方式。业务同学重点检查规则与操作结果，开发者还可以结合代码差异、接口和自动化测试进行审查。

## 一轮协作怎样推进

1. 说明谁要完成什么操作，给出业务数据和限制条件。
2. 让 AI Agent 先阅读现有项目，确认需要修改哪些部分。
3. 实现一个范围明确的功能，在运行中的应用里检查结果。
4. 把具体差异反馈给 AI Agent，修正后再次检查，再进入下一轮。

比如，“做一个订单系统”范围太大；“业务员只能提交自己的草稿订单，提交后状态变为待审批”就能直接对应页面操作、权限和状态检查。
