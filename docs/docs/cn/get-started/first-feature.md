# 让 AI Agent 做第一个功能

先做一个小型订单管理：登录后查看订单，新增一笔订单，再修改金额。数据保存到应用数据库，刷新后仍能看到。

## 说明这次要做什么

先完成[创建应用](./create-app)，保持开发服务运行，用AI Agent打开应用根目录。可以给它这段需求：

```text
先读取当前项目的 AGENTS.md 和相关开发指引。

加一个简单的订单管理功能：
- 登录后从菜单进入订单列表，可以新增和编辑订单。
- 订单包含订单号、客户名称和金额，金额不能为负数，订单号不能重复。
- 数据保存在应用数据库，刷新页面后仍能看到。
- 先不加审批、通知和复杂角色权限。
- 沿用项目的组件和中英文翻译，接口也要检查访问权限。

完成后实际验证新增、修改和刷新，报告修改了哪些文件、执行了哪些检查。
```

让 AI Agent 在当前应用里做这个功能。这里不需要创建一个单独发布的插件。

## 看它改了哪些地方

可以按下面的目录检查 AI Agent 的改动：

| 位置                                  | 用途                                                   |
| ------------------------------------- | ------------------------------------------------------ |
| `database/main/migrations/`           | 创建订单表，并限制订单号唯一                           |
| `server/routes/orders.ts`             | 提供读取、新增和修改接口，检查登录与访问权限、校验输入 |
| `server/routes/index.ts`              | 接入订单接口                                           |
| `client/pages/orders.tsx`             | 显示订单列表和新增、编辑表单                           |
| `client/routes.ts`                    | 添加订单页面和菜单入口                                 |
| `client/locales/en-US.ts`、`zh-CN.ts` | 添加中英文界面文字                                     |
| `package.json`、`pnpm-lock.yaml`      | 记录服务端需要的依赖及版本                             |

你不需要先看懂所有代码。先确认改动围绕需求展开，再实际使用功能。`client/` 是浏览器页面，`server/` 是服务端接口，`database/` 保存数据库结构变更。

## 新增一笔订单

以创建应用时的管理员登录，点击「订单管理」，再点击「新增订单」。填写：

| 字段       | 示例      |
| ---------- | --------- |
| 订单号     | `ORD-001` |
| 客户名称   | 青禾商贸  |
| 金额（元） | `1280`    |

![填写一笔订单](https://static-docs.nocobase.com/nb3-docs-20260916-order-form-cn.png)

点击「保存」，确认订单出现在列表中。刷新浏览器，检查订单仍在。这一步可以发现只修改了页面、没有真正保存到数据库的情况。

## 修改并检查结果

点击该订单的「编辑订单」，把金额改成 `1380` 后保存。再次刷新，列表应显示修改后的金额。

![修改金额并刷新后的订单列表](https://static-docs.nocobase.com/nb3-docs-20260916-orders-cn.png)

另外检查两种失败情况：再次新增 `ORD-001` 时应拒绝重复订单号；金额为负数时应拒绝保存。页面限制之外，服务端也需要拒绝非法请求。

## 检查没有通过时继续修改

遇到错误时，把实际命令和完整错误交给 AI Agent，让它解释并修复，再重新执行。不要把删除检查脚本或忽略报错当作完成。

接下来阅读[检查 AI Agent 的产出](../ai/reviewing-output.md)，把这种验证方式用到后续功能上。需要把需求说得更明确时，继续看[怎么提需求](../ai/writing-requirements.md)。
