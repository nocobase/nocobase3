# 快速开始

本教程以 IMAP/SMTP 邮箱为例，带你从搭建邮件中心到完成第一次收发。如果应用已经提供邮件功能，可以直接从第二步开始。

## 第一步：让 AI 搭建邮件中心

在已有的 NocoBase 3 应用中，把下面的需求交给 AI，并补充邮箱服务商和希望放置邮件入口的位置：

> 帮我在应用中添加邮件中心，接入公司的邮箱，让每个人关联自己的账户，阅读、回复和发送邮件，并能管理签名和模板。请告诉我需要提供哪些邮箱配置，以及搭建完成后从哪里进入。

告诉 AI 你使用的邮箱服务商，让它引导你准备所需信息并完成配置。IMAP/SMTP 需要确认服务器地址和连接方式；Gmail 和 Microsoft 365 需要在服务商平台配置 OAuth 应用，可按[AI 引导配置](./configuration.md#推荐让-ai-引导配置)逐步完成。

邮箱密码或授权码在关联账户时自行填写。搭建完成后，从 AI 告知的入口打开邮件功能。以下使用「账户管理」和「邮件中心」指代相应功能，具体名称以应用为准。

## 第二步：关联邮箱

打开账户管理，点击「关联账户」：

1. 选择已配置的邮箱服务商。
2. 选择首次同步的起始日期。第一次使用可以选择最近几天，减少等待时间。
3. 填写邮箱地址、用户名和密码。邮箱服务商要求授权码或应用专用密码时，填写该值。
4. 完成关联，确认账户状态正常。

使用 Gmail 或 Microsoft 365 授权接入时，按页面提示跳转到服务商完成授权。

首次关联成功后，系统会自动在后台同步所选日期范围内的邮件。首次同步需要一些时间，邮件越多，等待越久；可以在应用提供的同步记录中查看进度。

## 第三步：阅读邮件

打开邮件中心，查看已同步的邮件。选择一封邮件，阅读正文并查看附件；关联多个邮箱后，可以切换账户查看。

无需等待全部同步完成，即可先阅读已导入的邮件。暂时没有看到邮件时，可以稍后刷新列表；同步的日常用法见[同步邮箱](./usage.md#同步邮箱)。

## 第四步：发送一封邮件

点击写邮件，选择发件邮箱，填写收件人、主题和正文，发送到自己可以查收的另一个邮箱。

在收件邮箱中确认邮件已收到，正文和附件正常。也可以回复一封来信，体验在应用中处理邮件。发送出现异常时，可在应用提供的发送记录中查看原因。
