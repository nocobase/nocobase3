# 使用邮件

邮件功能由 AI 使用组件接入应用，具体入口和可用功能以你的应用为准。以下操作针对当前用户关联的邮箱；应用尚未提供邮件功能时，先完成[快速开始](./quick-start.md)。

## 管理邮箱账户

在账户管理中关联邮箱。一个用户可以关联多个账户，每个账户分别授权，并设置首次同步的起始日期。关联步骤见[快速开始](./quick-start.md#第二步关联邮箱)。

暂时不用的账户可以停用，停用期间不再发送或同步邮件。需要继续使用时重新启用；提示授权失效时，重新关联并完成授权。

移除账户会清理应用中的账户信息和本地同步数据，不会删除邮箱服务商处的邮件。

## 阅读和查找邮件

邮件中心统一展示多个账户的邮件，并标明来源账户。你可以切换账户和文件夹，也可以搜索邮件，按未读、星标或标签筛选。

选择邮件即可阅读正文、查看或下载附件。同一会话中的邮件会按服务商提供的信息展示在一起。打开邮件后会标记为已读，也可以手动改回未读。

部分邮件的正文可能尚未加载完成，按页面提示加载或重试即可。

## 同步邮箱

首次关联邮箱后，系统会自动同步所选日期范围内的邮件，之后定期同步新邮件。首次同步可能需要一些时间，期间可以先阅读已导入的内容。

需要主动获取新邮件时，使用同步操作。选中一个账户后，同步该邮箱；「同步全部邮箱」会同步可用的账户。刷新列表只显示应用已经同步的数据，不会主动从服务商获取新邮件。

同步进度和异常可在应用提供的同步记录中查看。自动同步间隔由应用统一配置，默认每 5 分钟一次。

IMAP/SMTP 主要同步新增邮件，暂不完整同步其他客户端的已读、删除和移动操作。

## 整理邮件

可以将邮件标记为已读或未读、添加星标，并根据邮箱支持的能力移动、归档或删除邮件。IMAP/SMTP 暂不支持移动到文件夹或移入回收站，需要时请在邮箱服务商的客户端中操作。永久删除会删除服务商处的邮件，操作前请确认内容。

标签、私有备注和待办标记用于在应用中整理邮件，重新同步后仍会保留。这些信息不会同步为服务商邮箱中的标签、备注或任务。

## 写信、回复和转发

点击写邮件，选择发件邮箱，填写收件人、主题和正文。可以添加附件、抄送和密送；账户有可用发件别名时，也可以选择别名发送。

阅读邮件时可以直接回复或转发。转发会保留原邮件内容，你可以在前面补充说明。

### 使用签名和模板

在账户管理中设置签名和模板。每个邮箱可以保存多个签名，并指定默认签名；写信时可以切换签名或不使用签名。

模板用于复用邮件主题和正文，属于当前用户。应用模板会替换当前主题和正文，使用前请确认已有内容是否需要保留。

如果应用已接入业务数据，模板还可以填入客户姓名等信息。发送前检查替换结果，未匹配的变量会保留原样。

### 保存草稿

写信时会自动保存草稿，重新打开页面后可以继续编辑。Gmail 和 Microsoft 365 还支持将草稿同步到服务商；IMAP/SMTP 草稿仅保存在应用中。

遇到草稿版本冲突时，按提示查看差异并选择保留的版本。关闭写信窗口时，如有未保存提示，请先处理修改。

### 定时发送

开启定时发送并选择时间。保存后，即使关闭浏览器，系统也会在指定时间发送；届时应用服务和邮箱账户需要正常可用。

### 分别发送

向多人发送且希望每人单独收到邮件时，可以使用分别发送。

发送后可在批量发送记录中查看每个收件人的结果。部分失败时，只重试失败项，避免重复发送。

## 查看发送结果

普通发送、定时发送和分别发送都会留下记录，可通过应用提供的发送记录入口查看。

服务商已接受邮件（`accepted`）不代表收件人一定收到或阅读。发送失败时查看错误原因；结果不确定（`unknown`）时，先确认邮件是否已经发出，再决定是否重试。
