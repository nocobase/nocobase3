# 邮件

邮件插件用于管理用户关联的邮箱，支持邮箱账户授权、邮件收发和邮件记录管理。你可以让 AI 使用邮件组件搭建独立的邮件中心，也可以把邮件功能放进客户、项目等业务页面，在处理业务时阅读和回复邮件。

## 可以做什么

- **管理多个邮箱**：每个用户关联自己的邮箱，在同一个邮件中心查看来信，按账户和文件夹筛选。
- **阅读和整理邮件**：搜索邮件、查看会话和附件，标记已读、星标、标签、私有备注和待办。
- **撰写和发送邮件**：写信、回复、转发，添加附件、抄送和密送，使用签名和模板。
- **安排发送时间**：保存草稿、定时发送，或向多个收件人分别发送邮件。
- **结合业务使用**：让 AI 按业务需求将邮件与客户、联系人、项目等记录关联，在业务详情中查看和回复相关邮件，并将业务数据用于邮件模板。

## 让邮件与业务数据关联

邮件可以成为业务记录的一部分。例如，在客户详情中查看与联系人的往来邮件，在项目页面中集中查看相关沟通，或从订单页面发起邮件，将客户姓名、订单编号等信息填入模板，减少页面切换和重复输入。

搭建时，向 AI 说明邮件与业务记录如何关联，例如按联系人的邮箱地址匹配往来邮件，或由用户手动将邮件关联到某个项目。AI 根据这些规则实现数据关联、邮件筛选和页面交互，并保留邮箱访问权限约束；具体接入方式见[应用开发](./development.md)。

例如，可以这样描述需求：

> 请在客户详情中加入邮件功能，根据该客户联系人的邮箱地址展示当前用户有权访问的往来邮件，支持直接阅读和回复。写信时可以选择客户联系人作为收件人，并将客户名称和联系人姓名填入邮件模板。

## 支持哪些邮箱

支持通过 Gmail、Microsoft 365 授权关联邮箱，也支持使用 IMAP/SMTP 接入其他邮箱。具体接入方式取决于邮箱服务商开放的服务，准备信息见[邮箱接入配置](./configuration.md)。

不同接入方式支持的整理、草稿和同步能力有所差异，使用时可查看[使用邮件](./usage.md)中的对应说明。

## 如何开始

先向 AI 描述邮件入口放在哪里、使用哪种邮箱，以及谁可以使用。AI 完成搭建后，用户在应用中关联自己的邮箱，即可开始收发邮件。页面名称和入口位置由你的应用决定。

- [快速开始](./quick-start.md)：搭建邮件中心，关联第一个邮箱并完成收发。
- [使用邮件](./usage.md)：了解账户管理、邮件整理和常用写信功能。
- [邮箱接入配置](./configuration.md)：准备服务商配置，按需调整同步和推送。
- [应用开发](./development.md)：定制组件、业务数据和接口接入。
