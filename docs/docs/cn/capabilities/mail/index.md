# 邮件

在 NocoBase 中，**邮件插件（Mail）**用于管理用户关联的邮箱，支持账户授权、邮件收发和邮件记录管理。你可以让 AI 使用邮件组件搭建独立的邮件中心，也可以把邮件功能放进客户、项目等业务页面，在处理业务时阅读和回复邮件。

如果你要发送审批结果、验证码或系统提醒，请使用[通知](../notification.md)的邮件渠道。邮件插件处理用户关联的邮箱，通知渠道处理应用主动发出的消息，两者的配置和记录彼此独立。

## 可以做什么

- **管理多个邮箱**：每个用户关联自己的邮箱，在同一个邮件中心查看来信，按账户和文件夹筛选。
- **阅读和整理邮件**：搜索邮件、查看会话和附件，标记已读、星标、标签、私有备注和待办。
- **撰写和发送邮件**：写信、回复、转发，添加附件、抄送和密送，使用签名和模板。
- **安排发送时间**：保存草稿、定时发送，或向多个收件人分别发送邮件。
- **结合业务使用**：让 AI 按业务需求将邮件与客户、联系人、项目等记录关联，在业务详情中查看和回复相关邮件，并将业务数据用于邮件模板。

## 让邮件与业务数据关联

邮件可以成为业务记录的一部分。比如，在客户详情中查看与联系人的往来邮件，在项目页面中集中查看相关沟通，或从订单页面发起邮件，将客户姓名、订单编号等信息填入模板，减少页面切换和重复输入。

搭建时，向 AI 说明邮件与业务记录如何关联，比如按联系人的邮箱地址匹配往来邮件，或由用户手动将邮件关联到某个项目。AI 根据这些规则实现数据关联、邮件筛选和页面交互，并保留邮箱访问权限约束；具体接入方式见[应用开发](./development.md)。

比如，可以这样描述需求：

> 请在客户详情中加入邮件功能，根据该客户联系人的邮箱地址展示当前用户有权访问的往来邮件，支持直接阅读和回复。写信时可以选择客户联系人作为收件人，并将客户名称和联系人姓名填入邮件模板。

## 支持哪些邮箱

支持通过 Gmail、Microsoft 365 授权关联邮箱，也支持使用 IMAP/SMTP 接入其他邮箱。默认优先选择 OAuth 接入；只有当邮箱服务商没有可用的内置 OAuth 接入时，才使用 IMAP/SMTP。

| 能力                          | Gmail         | Microsoft 365   | IMAP/SMTP                      |
| ----------------------------- | ------------- | --------------- | ------------------------------ |
| 账户关联                      | OAuth         | OAuth           | 邮箱地址、用户名和密码或授权码 |
| 收信、发信和附件              | 支持          | 支持            | 支持                           |
| 自动同步和手动同步            | 支持          | 支持            | 支持，主要发现新增邮件         |
| 推送同步                      | Gmail Pub/Sub | Microsoft Graph | 不支持                         |
| 服务商草稿同步                | 支持          | 支持            | 不支持                         |
| 发件别名                      | 支持          | 支持            | 不支持                         |
| 移动到服务商文件夹            | 支持          | 支持            | 不支持                         |
| NocoBase 标签、私有备注和待办 | 支持          | 支持            | 支持                           |

不同接入方式支持的整理、草稿和同步能力有所差异。完整配置见[邮箱接入配置](./configuration.md)，使用限制见[使用邮件](./usage.md)。
