# 检查权限结果

在设置 → 权限 → 权限检查器中选择一个用户或其他授权对象，再选择资源和操作。检查器需要独立的检查权限；有权维护权限集不代表自动能使用它。

结果区分允许、受限、拒绝和检查失败。查看详情可以了解权限集和规则来源、各个数据范围，以及必要时的字段和执行条件。配置标记表示存在授权配置，不代表每一条业务记录都可以访问；检查器也不统计可访问的记录数量。

## 为什么能编辑却不能提交

工程师可能能编辑自己编制的报价，但报价所属项目不在其负责区域。检查“编辑”与“提交”的各个范围，通常能发现提交多了项目条件。报价金额不合法或状态已经变更则属于业务校验，需要结合业务页面或请求错误判断。

## 如何看团队权限

检查用户会包含系统解析出的团队成员关系和已认证用户受众。直接检查团队时，结果只描述分配给团队本身的能力，并不合并团队所有成员的个人权限。需要知道某人的实际权限时，请选择该用户。

排查时依次确认：安装的功能、岗位分配、团队是否有效、操作和范围是否选对、共享是否包含所有必要记录、限制是否排除了目标，以及业务状态是否允许操作。最后用该用户的真实请求验证，不能仅凭页面按钮或检查器配置标记得出结论。
