# 默认数据范围

默认数据范围适合稳定的共同基线。例如所有有“查看报价”权限的人都可以查阅非保密报价，而“编辑报价”仍只允许本人编制。

在设置 → 权限 → 默认数据范围中选择业务资源、操作和具体范围，配置条件并保存。多个操作或多表范围应分别配置。清除规则会移除这个基线，不会移除用户的岗位操作权限，也不会撤销其他共享。

默认范围会与岗位配置和共享一起提供正向访问，不是只有岗位未配置时才使用。因此不要将“查看”的宽范围直接复制给“编辑”。验证时至少使用一位有操作权限和一位没有操作权限的用户；后者不能因为默认范围而获得操作能力。

开发新范围或不知道如何选时，使用[AI 需求模板](develop-with-ai)，明确说出“所有哪些操作的持有者都可以访问哪些记录”。
