# 共享规则

共享规则适合临时交接和跨职责协作。例如把指定报价交给提案团队编辑和提交，但不开放全部报价。接收对象必须已经拥有对应业务操作；共享只补数据范围。

在设置 → 权限 → 共享规则中创建规则，填写用途明确的名称，选择业务资源、操作、范围以及接收用户或团队。可以选择具体记录，也可以按系统提供的范围策略动态匹配。

如果提交依赖父项目，需要同时给该操作的报价范围和项目范围配置共享。查看、编辑、提交也各自独立：共享“编辑”不会自然共享“提交”。一条规则中不同范围的记录选择互不替代。

验证协作人员能处理交接记录，同时不能处理未交接记录；再移除一个必要范围，确认操作被拒绝。任务结束后撤销相应共享，并检查是否仍存在其他直接或团队授权。限制规则仍可能阻止已共享记录。
