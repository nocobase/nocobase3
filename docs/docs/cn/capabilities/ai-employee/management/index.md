# 管理 AI 员工

进入管理后台的「AI 员工」设置。这里集中管理 LLM 服务和 AI 员工，是业务管理员日常维护员工的入口。

## 管理流程

1. 在「LLM 服务」页签确认至少一个模型已启用
2. 在「AI 员工」页签查看员工列表
3. 打开员工详情，检查简介、模型、技能和工具
4. 按需要启用、停用或调整员工
5. 用聊天或预览入口发送测试消息
6. 确认普通用户只能看到目标角色允许使用的员工

## 启用和停用员工

停用员工后，新的聊天入口不应再向用户推荐它。已有会话的处理方式取决于当前会话和权限策略，停用前应先确认是否有正在进行的任务。

停用前建议：

- 确认是否有其他员工可以接替
- 检查业务页面上的快捷入口
- 通知使用该员工的角色
- 保留必要的历史会话用于排查

## 模型配置

在员工详情中检查默认模型和模型限制。员工要使用的模型必须同时满足：

- LLM 服务已配置
- 模型已经启用
- 当前用户有权使用
- 员工的模型限制允许使用

## 测试员工

测试时给出一条能验证职责的具体消息，比如：

```text
请读取当前订单信息，判断是否符合退货条件，并列出缺少的材料。
```

同时检查：

- 员工是否使用了预期模型
- 工具调用是否需要确认
- 返回内容是否引用了实际业务数据
- 无权访问的数据是否被拒绝
- 会话是否能继续对话
