# Legacy implementation source map

The reference implementation is `packages/pro-plugins/@nocobase/plugin-action-template-print` in the legacy NocoBase repository. These notes were derived on 2026-09-17 from its local source; the plugin repository HEAD was `23b8bd0d9b80ce760ee099eb2a5c3afdda044d7c`, and its manifest version was `2.2.5`. This identifies the inspection baseline, not a guarantee that another checkout has identical files. No legacy source checkout or absolute local path is required to use this Skill.

All paths below are relative to that legacy plugin directory. They describe historical internals; never import them into a v3 App. The examples in this Skill are small adaptation examples, not a vendored copy of the legacy runtime.

## Existing regression anchors

- `src/server/__tests__/middleware.test.ts`: inspect request, permission, filter, and binary-response scenarios before translating them to the target App's route tests.
- `src/server/render/image-handler/__tests__/stable-file-url.test.ts`: stable file URL handling and the boundary between file resolution and fallback.
- `src/server/render/pre-built-process/xlsx-process/__tests__/rich-data-pre-process.test.ts`: only template-bearing rich cells should be transformed.
- `src/server/render/post-process/__tests__/docx-spacing.test.ts`: disabled spacing values, text-run boundaries, breaks, and existing joiners.
- `src/server/__tests__/post-process.test.ts`: Office postprocessing fixtures; validate generated artifacts rather than copying assertions mechanically.

## Distinguish lessons from APIs

Preserve the separation of authorized data loading, formatting, Office processing, and conversion. Reimplement framework integration through the installed v3 contracts. Address the old code's raw attachment-ID reads, unrestricted remote fetches, filesystem substring matching, fixed PNG assumptions, post-fetch row cap, full-data logging, and filtered-page offset reset where those branches are relevant. These are reasons for targeted adaptation, not requirements to add every legacy feature to a new application.
