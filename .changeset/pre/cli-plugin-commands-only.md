Remove `nb3 app create`, `dev`, `info`, `config`, `destroy`, `deploy`, `pull`, `list` and the whole `nb3 hub` topic, leaving the five `nb3 app plugin *` commands the repository and generated applications actually call. Those commands came from an earlier plan where a user installed `nb3` globally and created projects with it; projects are generated by `pnpm create @nocobase/app` and run through their own scripts instead, so nothing invoked them and three were never implemented. A generated hub no longer gets a `.nb3/` directory either, since only the removed commands read it.
