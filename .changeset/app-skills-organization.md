Add an application development reference for building an organisation dimension, such as a department tree with memberships, and wiring it into authorization as an inherited subject type. It covers the model, a self-contained migration, the organisation service, routes, a settings page that uses one localized name for the menu entry, the settings item and the subject type, seeded titles stored as translation descriptors, department attributes that feed business data scopes through a sync, session refresh after membership changes, seeds that assign existing permission sets to departments and job roles to people, a test matrix and the common pitfalls, and it is linked from the Skill's reference table and the authorization reference.
